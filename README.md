# PressCraft

Ein geplantes, vollständig Open-Source und self-hostbares Content-Management-System als moderne Alternative zu WordPress — mit visuellem WYSIWYG-Seiteneditor, programmierbaren/visuell konfigurierbaren Themes und einem erweiterbaren Plugin-System.

Das Projekt befindet sich aktuell in der **Konzeptions- und Planungsphase**. Es existiert noch kein Code. Der Technologie-Stack und die wichtigsten Architekturentscheidungen stehen bereits (siehe unten), die konkrete Monorepo-Struktur und das Datenmodell folgen als nächster Schritt.

## Dokumentation

- [`docs/00-brief/initial-brief.md`](docs/00-brief/initial-brief.md) — die ursprüngliche Projektbeschreibung und der Ausgangsauftrag.
